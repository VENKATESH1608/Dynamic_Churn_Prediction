# Dynamic Churn Prediction using Machine Learning

## Project Overview
This project is a web-based system designed to predict telecom customer churn. By identifying customers likely to leave, the system enables proactive retention strategies, helping businesses improve customer loyalty and reduce revenue loss.

## Features
- Web-based interface for user interaction and prediction requests.
- Predicts customer churn using Machine Learning models.
- Implements Decision Tree and Support Vector Machine (SVM) models.
- Provides actionable insights for customer retention strategies.
- Evaluates model performance and explores advanced ML techniques for optimization.

## Dataset
The project uses a telecom customer dataset containing features such as:
- Customer demographics (age, gender, location, etc.)
- Account information (tenure, subscription plan, services used)
- Usage patterns (call duration, data usage, complaints)
